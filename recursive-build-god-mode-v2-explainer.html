The Recursive Engine

One loop is never "just coding." Every pass is full-system quality work with explicit decision logic.

Loop 01

Define objective, constraints, and measurable evidence target.

  • Pick the highest-risk unresolved objective, not the easiest task.
  • Treat review/testing as first-class work, never optional cleanup.
  • Continue looping while any blocker or weak gate remains.
  • Exit only with sustained gate confidence, not one lucky pass.

Hard Blockers

  • Any open P0 defect
  • Any open P1 defect
  • Critical tests not fully passing
  • Any required gate not in pass state
  • New high-severity regression in current loop
  • Rollback path unvalidated for runtime/deploy changes
